# Join With an Invite Link or Access Code

This guide explains the two ways members can receive their assigned Discord roles:
1. **Joining with a Dedicated Role Invite Link** (automatic upon server join)
2. **Entering a 6-Digit Access Code via `/enter_role`** (self-service inside Discord)

## Method 1: Joining with a Dedicated Role Invite Link

If you received a custom Discord invite link (for example, `https://discord.gg/abc123xyz`):

### How It Works
Each custom invite link generated by the bot (via `/submitrole` or the Web Admin `/admin/role-access` page) is paired directly with a specific Discord role in the bot's database. When you click that link and join the server, the bot's `on_member_join` event automatically calculates invite use counts, resolves your mapped role, and assigns it to your account immediately.

### Step-by-Step Instructions
1. **Click the invite link** provided to you by a server moderator or team lead.
2. **Accept the invite** in your web browser or Discord client.
3. Complete any standard Discord server onboarding prompts or community rules agreements if prompted.
4. **Done!** The bot assigns your role in the background as soon as you connect.

### Verification
- Look at your username in the server member list on the right side of Discord.
- Your assigned role badge and color will appear immediately.
- You will instantly have access to role-restricted channels associated with that role.

## Method 2: Entering a 6-Digit Access Code with `/enter_role`

If you received a **6-digit access code** (for example, `482910`), or if you joined using a general Discord invite link before receiving your code:

### How It Works
The `/enter_role` slash command allows any member already in the server to claim their mapped role directly inside Discord by submitting their assigned 6-digit access code through a secure interactive modal popup.

### Step-by-Step Instructions

1. **Navigate to a Command-Enabled Channel**  
   Open any text channel where bot commands are permitted (such as `#bot-commands`, `#general`, `#welcome`, or your server's designated command channel).

2. **Trigger the `/enter_role` Slash Command**  
   In the chat input box, type:
   ```text
   /enter_role
   ```
   Select `/enter_role` from the Discord slash command autocomplete list and press **Enter**.

3. **Fill in the Modal Popup Dialog**  
   A Discord dialog window titled **"Enter Role Code"** will appear:
   - Click in the **"6-digit code"** input field.
   - Enter your exact 6-digit numeric access code (e.g., `482910`).
   - Click **Submit**.

4. **Receive Instant Private Confirmation**  
   The bot processes your code against active server mappings in real time and sends an **ephemeral (private)** response that only you can see:
   - **Success:**  
     `✅ You've been given the **<Role Name>** role!`  
     *(Your role is immediately granted and permissions take effect instantly).*
   - **Invalid Code:**  
     `❌ Invalid code.`  
     *(The code was entered incorrectly, expired, or has been paused/disabled by an administrator).*
   - **Role Missing:**  
     `❌ Role not found.`  
     *(The mapped Discord role was deleted or renamed in server settings).*

## Which Method Should You Use?

| Member Situation | Recommended Method | Notes |
|---|---|---|
| New member with a custom role invite link | **Method 1 (Invite Link)** | Click link and join; role is assigned automatically with zero manual steps. |
| New member with a 6-digit code | **Method 2 (`/enter_role`)** | Join server first via any standard invite, then run `/enter_role` to claim role. |
| Existing member receiving a new role or promotion | **Method 2 (`/enter_role`)** | Run `/enter_role` directly in chat without needing to leave or rejoin. |
| Custom invite link didn't assign role automatically | **Method 2 (`/enter_role`)** | Use the 6-digit code paired with that invite link as a fallback. |

## Troubleshooting & Frequently Asked Questions

### 1. I clicked the invite link, joined the server, but did not receive my role.
- **Cause:** In rare cases of high traffic, multiple members joining simultaneously in the exact same second can cause Discord's invite use counter to be ambiguous, or the invite mapping might be temporarily paused.
- **Solution:** If you were provided with the 6-digit code that pairs with the invite, run `/enter_role` in any channel, enter the code, and submit. If you don't have the code, message the server moderator who invited you.

### 2. The `/enter_role` popup says "❌ Invalid code."
- **Double-check the digits:** Ensure you entered exactly 6 digits with no letters, spaces, or symbols.
- **Check code status:** Codes are case-insensitive and numeric. If you copied the code correctly, contact the person who provided it to ensure the mapping status is set to `Active` in the server's role access list.

### 3. "Discord expired your /enter_role prompt before the code window could open."
- **Cause:** Discord client network latency or slow connection during modal creation.
- **Solution:** Simply type `/enter_role` and run the command again.

### 4. What happens if I already have the role?
- The command is completely safe and idempotent. If you submit a code for a role you already possess, Discord retains your role without error.

### 5. Can other members see my code or my command response?
- **No.** The `/enter_role` modal form and the bot's confirmation/error messages are strictly **ephemeral** (visible only to your Discord client). Other server members cannot see your code or your submission.
